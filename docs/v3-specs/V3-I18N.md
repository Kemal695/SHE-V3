# V3 — Internationalization (Amharic First, English Second)

**Status:** Locked
**Last updated:** 2024-Q4
**Owner:** Mobile/Frontend Engineer + Lead Engineer

---

## 0. Scope

V3 targets Ethiopia exclusively (ADR-010). Amharic is the primary language; English is secondary. This document specifies language priorities, Flutter i18n implementation, Amharic typography, voice prompts, and cultural considerations (calendar, names, phone, currency, colors, wake word).

---

## 1. Language priorities

| Language | Priority | Coverage | Status |
|---|---|---|---|
| Amharic (አማርኛ) | **Primary** | 100% UI strings, voice prompts, error messages, push notifications | V3 GA |
| English | Secondary | 100% UI strings | V3 GA |
| Oromo (Afaan Oromoo) | Tertiary | V3.1 — largest ethnic group (~35% of population) | V3.1 |
| Tigrinya (ትግርኛ) | Quaternary | V3.1 — Tigray region (~6% of population) | V3.1 |

**Decision:** Ship V3 GA with Amharic + English only. Adding Oromo + Tigrinya in V3.1 once Amharic localization is proven stable and we have native-speaker reviewers for each additional language.

## 2. Flutter i18n

### 2.1 ARB files

```
mobile/lib/l10n/
├── app_en.arb       # English (source)
├── app_am.arb       # Amharic (primary)
└── l10n.yaml        # config
```

**`l10n.yaml`:**
```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
preferred-supported-locales: [am, en]
```

Code generation: `flutter gen-l10n --template=app_en.arb` (runs in CI on every PR that touches `lib/l10n/`).

### 2.2 Locale detection

On first launch:
1. Detect system locale
2. If `am` (Amharic) → default to Amharic
3. Else → default to English
4. User can override in Settings → Language (Amharic / English / System)

Override stored in `shared_preferences` (survives app restart). On every app launch, Riverpod `LocaleProvider` reads override (or system locale if no override) and calls `context.read(localeProvider).setLocale(...)`.

### 2.3 String coverage rule

Every user-facing string in the app must be in **both** `app_en.arb` and `app_am.arb`. CI gate (GitHub Action `flutter gen-l10n --check-complete`) fails the build if any key is missing from either file. Exception: developer-facing strings (stack traces, debug logs) are English-only.

## 3. Amharic typography

### 3.1 Font

- **Amharic:** Noto Sans Ethiopic (Google Fonts, OFL license)
- **Latin (English fallback):** Inter (V3-DESIGN-SYSTEM.md §2.1)
- **Monospace:** JetBrains Mono (for device IDs, technical data)

Noto Sans Ethiopic is bundled in the app assets (not loaded from Google Fonts CDN — Ethiopian internet is unreliable). Font file is ~1.2 MB; bundled in `mobile/assets/fonts/`.

### 3.2 Line height

- **Amharic:** line-height 1.6 (Amharic has tall ascenders + descenders that need vertical room)
- **English:** line-height 1.4
- Applied via `TextStyle(height: _locale == 'am' ? 1.6 : 1.4)`

### 3.3 Button + form width

- **Amharic text is ~30% wider** than equivalent English (e.g., "Settings" = 8 chars; "ቅንብሮች" = 6 Amharic chars but visually wider)
- Buttons: allow 30% more horizontal width for Amharic
- Form labels: top-aligned (not inline) to accommodate wider text without truncation
- Long Amharic strings: wrap at word boundaries; never truncate mid-word (Amharic words can be very long due to suffixes)

### 3.4 RTL considerations

Amharic is **LTR** (left-to-right), same as English. No RTL layout needed. (If we add Arabic in the future, that would require RTL support — out of scope for V3.)

## 4. Voice prompts (Amharic)

### 4.1 Wake word

- **Picovoice Porcupine custom wake word:** "Hey Sheba" (English phonetics)
- **Amharic alternative:** "ሰበኣ" (Sheba) — recognized alongside English by the same Porcupine model
- **Why English phonetics:** Picovoice's custom-wake-word service works best on Latin-script phonetics. A fully-Amharic wake word ("ሰላም ሸባ" — "Hello Sheba") was considered but rejected — see ADR-006 §Consequences (Neutral)
- **Note:** Picovoice model is trained per language. The "Hey Sheba" model handles both English and Amharic accents. If we add Oromo in V3.1, a new wake-word model would be needed for Oromo accents.

### 4.2 Intent examples

Intent inference (Picovoice Rhino) handles fixed-vocabulary bilingual intents:

| English intent | Amharic intent | Action |
|---|---|---|
| "Hey Sheba, turn on the living room light" | "ሰበኣ የሳሎን ብርሃን አብር" | Toggle relay with Label="Living Room Light" |
| "Hey Sheba, turn off relay 3" | "ሰበኣ ሬሌ 3 አጥፋ" | Toggle relay channel 3 OFF |
| "Hey Sheba, activate movie night scene" | "ሰበኣ movie night ስኪን አስጀምር" | Trigger scene by name |
| "Hey Sheba, what's the power usage" | "ሰበኣ የኃይል መጠን ስንት ነው" | Speak current `power_consumption` via TTS |

### 4.3 TTS (Text-to-Speech)

For voice responses (e.g., "Power usage is 264 watts"):

- **Android:** Use Android built-in TTS (`android.speech.tts`). Amharic supported on Android 13+ (platform TTS engine). For Android 8-12, use pre-recorded audio clips for the limited voice-response vocabulary (~20 phrases).
- **iOS:** Use AVSpeechSynthesizer. Amharic supported on iOS 16+. For iOS 15, use pre-recorded clips.

Pre-recorded clips (Amharic + English) stored in `mobile/assets/audio/`. Total ~50 clips, ~2 MB.

## 5. Cultural considerations

### 5.1 Ethiopian calendar

- **13 months:** 12 months × 30 days + 1 month (Pagume) × 5 or 6 days (leap year)
- **7-8 years behind Gregorian** (Ethiopian year 2017 = Gregorian 2024/2025)
- **New year:** September 11 (or 12 in leap year)
- **Date format:** DD/MM/YYYY (Ethiopian calendar) — configurable in Settings
- **First day of week:** Sunday (Ethiopian week starts Sunday)
- **Time:** Ethiopia commonly uses 12-hour clock from dawn (6 AM = "12 o'clock" in Ethiopian time). For V3, we use standard 24-hour UTC + 3 (East Africa Time) and 12-hour AM/PM display — Ethiopian traditional time is too confusing for a smart home scheduling UI.

Implementation: `EthiopianCalendar` utility class in `mobile/lib/core/utils/` (port of [ethiopian-calendar](https://github.com/geezorg/ethiopian-calendar) JS library). Toggle in Settings: "Use Ethiopian calendar" (default ON if locale=am, OFF if locale=en).

### 5.2 Names

- **Ethiopian naming convention:** First name + father's name (no family surname). Example: "Abebe Bekele" = Abebe (given) + Bekele (father's name). There is no shared family name across siblings.
- **Forms use "Full name" field** (single text input), not "First name / Last name"
- **Validation:** `^[\p{L}\s'\-]{2,100}$` (Unicode letters, spaces, apostrophes, hyphens — supports Amharic + Latin)
- **Display:** Always show full name in UI; never split into "First" + "Last" for greeting (would feel wrong to Ethiopian users — "Hello, Abebe" not "Hello, Mr. Bekele")

### 5.3 Phone numbers

- **Format:** `+251 9XX XXX XXX` (mobile) — country code +251, then 9 + 8 digits
- **Validation regex:** `^(\+251|0)?9\d{8}$` (accepts `+251911234567`, `0911234567`, or `911234567`)
- **Display:** `+251 911 234 567` (spaces for readability)
- **SMS:** Not used in V3 (no SMS gateway integrated). Push notifications via FCM/APNs only.

### 5.4 Currency

- **Symbol:** ብር (Amharic) or ETB (English)
- **ISO code:** ETB
- **Format:** 1,234.56 (comma thousands separator, dot decimal)
- **Display in app:** Use `ብር` for Amharic locale, `ETB` for English locale
- **No cents for amounts < 1 ETB** (round to nearest birr)
- **Conversion rate:** ~55 ETB = $1 USD (used internally for B2B pricing in USD)

Example formatting:
```dart
String formatEtb(double amount, Locale locale) {
  final formatted = amount.toStringAsFixed(2).replaceAllMapped(
    RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))'),
    (m) => '${m[1]},'
  );
  return locale.languageCode == 'am' ? '$formatted ብር' : '$formatted ETB';
}
// → formatEtb(1234.56, Locale('am')) → "1,234.56 ብር"
// → formatEtb(1234.56, Locale('en')) → "1,234.56 ETB"
```

### 5.5 Colors

- **Avoid red + green combinations** (Ethiopian flag colors) in non-essential UI — culturally sensitive
- **Use blue (trust, technology) + white (cleanliness) as primary brand** per V3-DESIGN-SYSTEM.md
- **NO indigo or blue-purple** hues — system rule (V3-DESIGN-SYSTEM.md §1.1)
- **SHE brand colors:** Deep Navy `#0B1D37` (background) + Bright Sky Blue `#56B4FA` (primary action)
- **Status colors:** Green (`#00C853`) = online/success, Red (`#D50000`) = offline/error, Amber (`#FFAB00`) = warning — these are functional, not decorative, so the red+green avoidance doesn't apply

### 5.6 Date + time formatting

| Locale | Date format | Time format | Example |
|---|---|---|---|
| Amharic (Ethiopian calendar) | DD/MM/YYYY | 12-hour AM/PM | 15/04/2017 እ.ኤ.አ. 3:30 ከሰዓት |
| English (Gregorian) | DD/MM/YYYY | 12-hour AM/PM | 23/10/2024 3:30 PM |

Both use DD/MM/YYYY (Ethiopian convention — not US MM/DD/YYYY, not ISO YYYY-MM-DD in user-facing UI).

### 5.7 Number formatting

- Western Arabic numerals (0-9) — not Ethiopic numerals (፩፪፫...)
- Ethiopic numerals are rarely used in modern Ethiopian digital products; using them would hurt comprehension
- Decimal separator: dot (.)
- Thousands separator: comma (,)
- Example: 1,234.56 (same as English)

## 6. Push notifications

- **Language:** Determined by recipient's app locale setting (stored in `users.locale` column)
- **Title + body** translated in Spring Boot (uses resource bundles `messages_am.properties` + `messages_en.properties`)
- **Example:**
  - Amharic: "የኃይል መጠን መጨመር" / "የእርስዎ የኃይል መጠን ከመደበኛው 3 እጥፍ ጨምሯል"
  - English: "Power spike detected" / "Your power consumption is 3× higher than usual"

## 7. Localization workflow

### 7.1 String addition

1. Developer adds key to `app_en.arb` (English source)
2. CI gate fails: "Missing am translation for key X"
3. Developer adds Amharic translation to `app_am.arb`
4. CI passes; PR mergeable

### 7.2 Translation review

- All Amharic strings reviewed by a native Amharic speaker (Lead Engineer or contractor) before merge
- Glossary maintained in `mobile/lib/l10n/GLOSSARY.md` — canonical translations for technical terms:
  - "device" → "መሣሪያ"
  - "relay" → "ሬሌ" (transliteration, common usage)
  - "automation" → "ራስ-ሰር ተግባር"
  - "scene" → "ስኪን" (transliteration)
  - "subscription" → "ደንበኛነት"

### 7.3 External translator

For V3.1 (Oromo + Tigrinya), we will engage a professional translation service:
- Ethiopian Languages Academy (Addis Ababa) — official body
- Or freelance translators via Upwork (with native-speaker review)
